# Component Screenshots

Place screenshots in this directory with the following filenames:

## SimPlaylist
- `simplaylist-overview.png` - Main view with album grouping and tracks
- `simplaylist-settings.png` - Preferences page with grouping patterns

## Playlist Organizer
- `plorg-overview.png` - Main tree view with folders and playlists
- `plorg-import-menu.png` - Import menu dropdown
- `plorg-path-mapping.png` - Path mapping dialog
- `plorg-settings.png` - Preferences page

## Waveform Seekbar
- `waveform-layered-split.png` - Layered style with Split channels, hover readout and loudness summary
- `waveform-twotone-split.png`, `waveform-glow-split.png`, `waveform-heat-split.png` - Two-tone (P31 green), Glow and Heat styles with Split channels
- `waveform-classic-solid.png` - Seekbar in the Classic Solid style
- `waveform-overview-v3.png` - Layered style (1.x look), used as the hero image of docs/waveform.md
- `waveform-settings-v3.png` - Preferences page (Appearance, Scales, Overlays, Played part, Cache)
- `waveform-overview-v2.png`, `waveform-settings-v2.png`, `waveform-overview.png`, `waveform-settings.png` - Previous screenshots, no longer referenced; kept so links from older forum threads still resolve

## Spectrum Analyzer
- `spectrum-curve.png` - Curve mode with color bars
- `spectrum-bars.png`, `spectrum-bars-dense.png` - Bars mode, normal and dense
- `spectrum-overview.png` - Curve mode, filled style, below the waveform seekbar (pre-1.0 labels)
- `spectrum-settings.png` - Preferences page with analysis, dynamics and appearance options

## Vectorscope
- `vectorscope-scope.png` - Band colors and the three-band correlation meter
- `vectorscope-overview.png` - Beside the Spectrum Analyzer, meter on the right
- `vectorscope-panel.png`, `vectorscope-bands.png` - Three-band correlation; band-colored trace
- `vectorscope-settings.png` - Preferences page

## Queue Manager
- `queuemanager-overview.png` - Queue with queued tracks

## Last.fm Scrobbler
- `scrobbler-settings.png` - Preferences page with account and options

## Guidelines
- PNG format preferred
- Reasonable dimensions (800-1200px width typical)
- Dark theme screenshots preferred for consistency
- Crop to show relevant UI elements
